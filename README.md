# game-dev

Game development with Godot 4: GDScript conventions, game loop architecture.

| Skill | Source |
| --- | --- |
| `skillset-godot-gdscript` | custom |
| `skillset-game-loop-architecture` | custom |

| MCP server | Needs |
| --- | --- |
| `godot` ([@coding-solo/godot-mcp](https://www.npmjs.com/package/@coding-solo/godot-mcp)) | Godot 4 installed (set `GODOT_PATH` if not auto-detected) |

## Install

```bash
npx topic-skillset add game-dev
npx skills add https://github.com/Satcomx00-x00/SkillSet/tree/game-dev
/plugin install game-dev@skillset   # after: /plugin marketplace add Satcomx00-x00/SkillSet
```

Add third-party skills to `skillset.json` and run `skillset sync`. Tooling lives on [`main`](https://github.com/Satcomx00-x00/SkillSet).
