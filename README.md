# coding

Language-agnostic software engineering: TDD, debugging, design, code review, commits. Language skills live on `code-typescript`, `code-python`, `code-rust`.

| Skill | Source |
| --- | --- |
| `skillset-conventional-commits` | custom |
| `skillset-setup` | generated by `skillset sync`: runs every setup skill (`/skillset-setup`) |
| `skillset-mattpocock-tdd`, `skillset-mattpocock-diagnosing-bugs`, `skillset-mattpocock-codebase-design`, `skillset-mattpocock-code-review`, `skillset-mattpocock-setup-matt-pocock-skills` | [mattpocock/skills](https://github.com/mattpocock/skills) (MIT, vendored) |
| `skillset-ponytail`, `skillset-ponytail-review` | [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) (MIT, vendored) |

| MCP server | Needs |
| --- | --- |
| `context7` | Node 22+ |
| `sequential-thinking` | Node 22+ |
| `github` | `GITHUB_TOKEN` env var |

## First run

After installing, type `/skillset-setup` in your agent (in Claude Code plugin installs: `/coding:skillset-setup`). It runs `skillset-mattpocock-setup-matt-pocock-skills` and any other installed setup skill, one after another.

## Install

```bash
npx topic-skillset add coding
npx skills add https://github.com/Satcomx00-x00/SkillSet/tree/coding
# Claude Code
/plugin marketplace add Satcomx00-x00/SkillSet
/plugin install coding@skillset
```

Vendored skills are pinned in `skills.lock.json`; edit `skillset.json` and run `skillset sync` to change them. Tooling and docs live on [`main`](https://github.com/Satcomx00-x00/SkillSet).
