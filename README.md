## Install

```bash
npx topic-skillset add docs
npx skills add https://github.com/Satcomx00-x00/SkillSet/tree/docs
/plugin install docs@skillset     # after: /plugin marketplace add Satcomx00-x00/SkillSet
```

Add third-party skills to `skillset.json` and run `skillset sync`. Tooling lives on [`main`](https://github.com/Satcomx00-x00/SkillSet).
