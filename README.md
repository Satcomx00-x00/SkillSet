Rust: idiomatic ownership, error handling, async with Tokio, and Clippy-clean code.

| Skill | Source |
| --- | --- |
| `rust-idioms` | custom |
| `rust-async` | custom |

No MCP servers yet. Pair with the [`coding`](https://github.com/Satcomx00-x00/SkillSet/tree/coding) topic for engineering workflow skills.

## Install

```bash
npx skill-set add code-rust
npx skills add https://github.com/Satcomx00-x00/SkillSet/tree/code-rust
/plugin install code-rust@skillset     # after: /plugin marketplace add Satcomx00-x00/SkillSet
```

Add third-party skills to `skillset.json` and run `skillset sync`. Tooling lives on [`main`](https://github.com/Satcomx00-x00/SkillSet).
