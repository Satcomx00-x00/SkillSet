# coding

Language-agnostic software engineering: TDD, debugging, design, code review, commits. Language skills live on `code-typescript`, `code-python`, `code-rust`.

| Skill | Source |
| --- | --- |
| `conventional-commits` | custom |
| `setup` | generated by `skillset sync`: runs every `setup-*` skill (`/setup`) |
| `tdd`, `diagnosing-bugs`, `codebase-design`, `code-review`, `setup-matt-pocock-skills` | [mattpocock/skills](https://github.com/mattpocock/skills) (MIT, vendored) |
| `ponytail`, `ponytail-review` | [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) (MIT, vendored) |

| MCP server | Needs |
| --- | --- |
| `context7` | Node 22+ |
| `sequential-thinking` | Node 22+ |
| `github` | `GITHUB_TOKEN` env var |

## First run

After installing, type `/setup` in your agent (in Claude Code plugin installs: `/coding:setup`). It runs `setup-matt-pocock-skills` and any other installed `setup-*` skill, one after another.

## Install

```bash
npx skill-set add coding
npx skills add https://github.com/Satcomx00-x00/SkillSet/tree/coding
# Claude Code
/plugin marketplace add Satcomx00-x00/SkillSet
/plugin install coding@skillset
```

Vendored skills are pinned in `skills.lock.json`; edit `skillset.json` and run `skillset sync` to change them. Tooling and docs live on [`main`](https://github.com/Satcomx00-x00/SkillSet).
