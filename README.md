# database

Databases: Postgres performance and best practices from Supabase, covering queries, indexes, connection pooling, locking, RLS security and schema design.

| Skill | Source |
| --- | --- |
| `skillset-supabase-postgres-best-practices` | [supabase/agent-skills](https://github.com/supabase/agent-skills/tree/c9be0e9/skills/supabase-postgres-best-practices) (MIT, vendored, weekly updates) |

Works for any Postgres, not only Supabase.

## Install

```bash
npx topic-skillset add database
npx skills add https://github.com/Satcomx00-x00/SkillSet/tree/database
/plugin install database@skillset     # after: /plugin marketplace add Satcomx00-x00/SkillSet
```

Add third-party skills to `skillset.json` and run `skillset sync`. Tooling lives on [`main`](https://github.com/Satcomx00-x00/SkillSet).
