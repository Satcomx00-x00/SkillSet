# 3d-dev

3D content pipelines: Blender Python scripting and glTF export/optimisation.

| Skill | Source |
| --- | --- |
| `blender-python` | custom |
| `gltf-pipeline` | custom |

| MCP server | Needs |
| --- | --- |
| `blender` ([blender-mcp](https://pypi.org/project/blender-mcp/)) | `uv` installed, Blender running with the blender-mcp add-on enabled |

## Install

```bash
npx topic-skillset add 3d-dev
npx skills add https://github.com/Satcomx00-x00/SkillSet/tree/3d-dev
/plugin install 3d-dev@skillset   # after: /plugin marketplace add Satcomx00-x00/SkillSet
```

Add third-party skills to `skillset.json` and run `skillset sync`. Tooling lives on [`main`](https://github.com/Satcomx00-x00/SkillSet).
