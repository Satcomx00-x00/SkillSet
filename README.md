# web

Web development: frontend (React, accessibility, performance) and backend (HTTP API design, auth, data).

| Skill | Source |
| --- | --- |
| `web-frontend` | custom |
| `web-backend` | custom |

| MCP server | Needs |
| --- | --- |
| `playwright` ([@playwright/mcp](https://github.com/microsoft/playwright-mcp)) | Node 22+; drives a browser to check pages |

Pair with [`code-typescript`](https://github.com/Satcomx00-x00/SkillSet/tree/code-typescript) and [`coding`](https://github.com/Satcomx00-x00/SkillSet/tree/coding).

## Install

```bash
npx skill-set add web
npx skills add https://github.com/Satcomx00-x00/SkillSet/tree/web
/plugin install web@skillset     # after: /plugin marketplace add Satcomx00-x00/SkillSet
```

Add third-party skills to `skillset.json` and run `skillset sync`. Tooling lives on [`main`](https://github.com/Satcomx00-x00/SkillSet).
